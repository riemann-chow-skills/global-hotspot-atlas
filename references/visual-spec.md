# 视觉与交互规范

## 一、界面结构

```
┌──────────────────────────────────────────────────────┐
│ Header  标题 · 时间窗 · 事件/实体/关系/区域 计数 · 关系图谱 │
├──────────┬───────────────────────────────┬───────────┤
│ 左栏      │  3D 地球画布                   │ 详情面板   │
│ 分类筛选  │  · 点阵陆地 + 大气辉光          │ (选中时滑出)│
│ 事件列表  │  · 事件光点（大小=热度，颜色=类别）│           │
│ (按热度)  │  · 选中时绘制大圆航线           │           │
│          │                               │           │
├──────────┴───────────────────────────────┴───────────┤
│ 关系图谱抽屉（按 G 展开）：力导向图，事件=环形节点         │
└──────────────────────────────────────────────────────┘
```

## 二、交互

| 操作 | 位置 | 效果 |
|---|---|---|
| 拖拽 | 地球 | 旋转（带惯性），松手 2.2 秒后恢复自动旋转 |
| 滚轮 | 地球 | 缩放 0.78×–2.7× |
| 点击光点 | 地球 | 选中事件：右滑出详情、地球左移让位、绘制关联航线 |
| 悬停光点 | 地球 | 浮出提示卡（类别 / 标题 / 地点 / 热度） |
| 点击空白 | 地球 | 关闭详情面板 |
| 点击列表项 | 左栏 | 选中并飞行定位到该事件 |
| 分类筛选 | 左栏顶部 | 同时过滤地球光点、列表、图谱节点 |
| `G` | 全局 | 展开/收起关系图谱 |
| `Esc` | 全局 | 先关详情，再关图谱 |
| 拖拽节点 | 图谱 | 手动调整布局（松手后力导向继续） |
| 滚轮 / 拖拽空白 | 图谱 | 缩放 / 平移（会关闭自动适配） |
| 点击节点 | 图谱 | 事件节点→选中事件；实体节点→聚焦其邻居子图 |
| 点击空白 | 图谱 | 退出聚焦，回到全图 |
| `重新布局` | 图谱工具条 | 重置物理参数与视角 |

打开图谱抽屉时，地球会自动缩小到 0.56× 并上移，保证不被遮挡；关闭时恢复。详情面板打开时地球中心左移约 40% 面板宽度。

## 四、地球为什么是点阵而不是贴图

渲染层用 Canvas2D 正射投影，陆地面貌由 `assets/landmask.b64` 提供的**纯物理陆地掩膜**（720×360 二值位图，陆地占比 29.9%）驱动，在其上铺约 7800 个斐波那契球面采样点。

这样做有三个原因：

1. **零依赖**：不需要 three.js、不需要瓦片服务、不需要任何 Key，断网可用。
2. **性能**：纯 2D 上下文，中端笔记本稳定 60fps。
3. **合规**：掩膜只区分"陆地/海洋"，**不包含任何国界线、行政区划、主权标注**。因此不构成地图边界表达，不涉及审图与主权表述问题。

如果用户要求"真实底图""街道级地图""能看到国界"，**不要修改这里的实现**，而是改用腾讯地图（见下一节）。

## 五、需要真实底图时的合规做法

本技能默认场景不涉及任何第三方地图服务。若用户明确要求真实底图：

- **允许**：腾讯地图、高德地图、百度地图、天地图
- **禁止**：Google Maps、Apple Maps、海外版 Bing、Mapbox、Leaflet + OpenStreetMap 直连瓦片，以及任何无资质的地图源

默认走腾讯地图 GL JS 的代理模式（前端不出现 Key）：

```html
<script>
  window._TMapSecurityConfig = {
    serviceHost: 'http://127.0.0.1:__WB_HTTP_PORT__/_TMapService/_wbt/__WB_TMAP_SECRET__',
  };
</script>
<script src="https://map.qq.com/api/gljs?v=1.exp"></script>
```

要点：

- `_TMapSecurityConfig` 必须在 SDK 的 `<script>` 之前设置
- SDK URL **不要**带 `?key=`
- `__WB_HTTP_PORT__` / `__WB_TMAP_SECRET__` 是运行时占位符，原样保留，不要替换
- 坐标系用 GCJ-02
- 容器必须有确定高度（`100vh` 或像素值），否则地图不渲染
- 不要传 `mapStyleId`（默认 Key 不支持自定义样式，会导致底图变灰）

若用户坚持用非白名单的地图源，先说明合规风险与具体原因，再主动替换为腾讯地图并给出完整可运行代码。

## 六、修改渲染层的注意事项

源码在 `assets/atlas/`，构建时由 `scripts/build.mjs` 内联进单文件 HTML：

| 文件 | 职责 |
|---|---|
| `template.html` | DOM 骨架 + 占位符 |
| `atlas.css` | 全部样式 |
| `globe.js` | 地球渲染与交互（`Globe` 类） |
| `graph.js` | 力导向图谱（`RelGraph` 类） |
| `app.js` | 数据规范化、视图装配、事件编排 |

改动后必须重新构建才会生效，并且要保证 `template.html` 里的 `__ATLAS_CSS__` / `__ATLAS_JS__` / `__ATLAS_DATA__` / `__LANDMASK_B64__` 四个占位符仍然存在——`build.mjs` 会检查未替换的占位符并报错。

关键不变量：

- `globe.js` 的投影约定：`y` 是朝向观察者的深度轴，`z` 是极轴，`x` 是屏幕横轴。改旋转逻辑时三个轴要一起改。
- 事件对象在 `setData` 时会被预处理出 `_v`（单位向量）、`_col`、`_rgb`，绘制阶段直接用，不要在每帧重算三角函数。
- 图谱的 `_fit()` 会自动把节点框进画布；用户手动缩放/平移后 `autoFit` 置 false，`重新布局` 时恢复。
- 数据注入用 `<script type="application/json">`，构建时已把 `</` 转义为 `<\/`，不要在数据里手写 `</script>`。
